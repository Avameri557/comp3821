\section{Social Optimum: Sioux Falls Network}

\subsection{Network and demand}

\begin{figure}[H]
  \centering
  \includestandalone[width=0.85\textwidth]{../diagrams/sioux_falls}
  \caption{Sioux Falls network. Every link costs $a + 0.01x$ in each direction; labels show $a$.}
\end{figure}

There are 24 nodes and 76 directed edges. Each agent draws an origin from $\{1, 2, 3\}$ and a destination
from $\{19, 20, 22\}$ using the run's seed, so demand varies by seed. With \texttt{forward\_only} there are
404 feasible paths. We use $N = 250$, 500 and 1000.

\subsection{Derivation}

\paragraph{Timing matters.} Edge $2 \to 6$ is the first edge for agents from 2 but the second for agents
from 1 via 2, so its users can cross it in different steps. With $X_{e,t}$ agents crossing $e$ in step
$t$,
\[
  SC = \sum_{e,\,t} X_{e,t}\,(a_e + 0.01\,X_{e,t}),
\]
minimised over how many agents of each origin--destination pair take each path. There is no closed form,
so we bracket the optimum numerically:
\begin{itemize}
  \item \textbf{Lower bound:} allow fractional agents and solve the resulting convex problem.
  \item \textbf{Upper bound:} round to whole agents, then move single agents between paths while that
        lowers the cost.
\end{itemize}
In all 153 cases (3 sizes $\times$ 51 seeds) the bounds are within 0.13 of each other, so we report the
upper bound as $\SCopt$.

\begin{itemize}
  \item The optimum \emph{staggers} agents in time. At $N = 1000$, edge $2 \to 6$ carries 271, 139 and 17
        agents at steps 0, 1 and 2, so later arrivals add nothing to earlier congestion. The static model
        cannot do this, so its optimum is 8--22\% higher and unreachable in the simulator.
  \item The gap between the simulator and the optimum grows with $N$: at the best $\alpha$ it is 0.6\%,
        2.5\% and 5.5\%.
  \item Reference lines for the sweep graphs: 21.773, 23.572 and 26.739 per agent.
\end{itemize}
